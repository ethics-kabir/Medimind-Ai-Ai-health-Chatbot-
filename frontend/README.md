# MediMind frontend

This React + Vite client is part of the full-stack MediMind AI Applications Lab project. See the repository's [main README](../README.md) for Python API setup, GitHub publishing, web deployment, and Android APK instructions.

From this folder, install dependencies and start the local client:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

The local Vite server forwards `/api` requests to the FastAPI backend at `http://127.0.0.1:8000`.
